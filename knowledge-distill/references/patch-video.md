# 补丁 B：视频（课程 / 访谈 / 教程 / 录屏）

适用素材：课程、访谈、教程、录屏等视频内容。

## 前置：多模态转写稿

先生成多模态转写稿，再蒸馏。抽帧、音轨抽取、ASR、OCR 的具体命令与失败退回见 `bootstrap.md`；转写稿需包含四路对齐信息：

1. 口播文本。
2. 画面事实（操作/代码/图表/公式）。
3. 屏幕文字（OCR）。
4. 动作与时间戳。

只有 ASR 文本不够——画面里出现而口播未念的内容（公式、架构图、代码缩进、按钮位置）必须单独捕获，否则标 unknown。

## 提取维度

1. **时序操作链**：把"先做什么再做什么"抽成有序步骤，每步挂 mm:ss。
2. **决策规则**：讲者在哪一步做了选择、依据是什么 → 转成"条件→动作"。
3. **演示中的隐性前提**：环境、版本、参数、前置配置，这类最容易被漏掉且最影响复现。
4. **反例与失败演示**：讲者明确说"这样不行/会报错"的片段，转成 fallback 分支。
5. **术语与概念**：仅提取有明确定义且可操作的术语，不做词汇表堆砌。

## 额外要求

- 区分"讲者的观点"与"可验证的事实"，观点标 Strong/Tentative inference。
- 版本敏感：所有涉及软件版本的结论必须记录演示时的版本号，无版本信息则标 unknown。
- 时效声明：注明素材发布时间，超过时效阈值（与用户确认，默认无阈值则全部声明发布时间）的操作性内容需提示"可能已过时"。

## 与总纲的衔接

- 阶段 1 的候选单元定位格式统一为 `mm:ss`（口播）+ 画面区域描述。
- 阶段 2 的三类时刻来源：决策规则 → 路由判断；失败演示 → 放弃判断；时序操作链的自然终点 → 结束判断。
