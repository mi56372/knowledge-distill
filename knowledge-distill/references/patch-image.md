# 补丁 C：图片 / 视觉素材

适用素材：截图、UI 稿、架构图、图表、设计稿、照片、板书、扫描件。

## 提取维度

1. **结构解析**：布局层级、组件树、区域划分、阅读顺序。
2. **可量化参数**：色值、字号、间距、比例、坐标、图例与单位——能提取数值的绝不写形容词。
3. **语义映射**：视觉元素 → 业务含义（如"红色虚线框 = 待废弃模块"），需有图注或上下文佐证。
4. **再生规格**：给出足以复现该视觉的规格描述（结构 + 参数 + 约束），而非"看起来简洁现代"。
5. **图文互证**：图中文字与外部文本冲突时，记录冲突而非擅自择一。

## 额外要求

- 每张关键图必须落到具体区域（左上/第3列/坐标范围），不接受"整张图说明"。
- 图中文字按 OCR 原样引用，不做润色；识别不清的字符标 `[unclear]`。OCR 工具与识别率不达标时的退回见 `bootstrap.md`。
- 禁止从图片推断未显示的交互行为、状态或数据；此类记 unknown。
- 若为设计稿/截图，产物应包含"可复现规格"章节，供后续生成或校验使用。

## 与总纲的衔接

- 阶段 1 的候选单元定位格式为"图号 + 区域（坐标范围或方位）"。
- 阶段 3 编译时，"可复现规格"章节放 references/，SKILL.md 只保留结构级规格与参数索引。
