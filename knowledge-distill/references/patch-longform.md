# 补丁 G：长内容（书 / 长视频课程 / 播客 / 访谈 / 有声书）

本 skill **自带**这一套长内容流程，不依赖、不转交任何其他 skill。方法论骨架参考 `cangjie-skill` 的 RIA-TV++（v2.5.0，Adler 分析阅读 + 五路并行提取 + 三重验证 + 晋级门 + RIA++ 六段卡），仅作参考：**不调用它的脚本、不读它的目录、不把任务甩给它**。证据纪律仍以本 skill 七条铁律为准。

## 与总纲的阶段映射

| 本补丁步骤 | 对应总纲阶段 | 产出 |
|---|---|---|
| K0 整篇理解 | 阶段 0/1 前置 | 内容总览（骨架 + 术语 + 局限 + 关键任务清单） |
| K1 五路提取 | 阶段 1 | 候选池（每条带形态定位） |
| K2 三重验证 | 阶段 2 | 四档判定 + 覆盖审计 |
| K3 晋级门 | 阶段 2 末 | 独立入口数决策（promoted / router） |
| K4 能力卡 | 阶段 3 | R/I/A1/A2/E/B 六段卡 |
| K5 压力测试 | 阶段 3→4 | 评测用例 + 回炉结论 |
| K6 编译交付 | 阶段 3/4 | single 或 pack 产物 |

## 第一步：分段与前置获取（按形态三选一）

| 形态 | 前置 | 分段单位 | 工具 |
|---|---|---|---|
| 书（电子/纸质/扫描） | 取全文文本；扫描件先 OCR | 章 → 节 → 段 | `bootstrap.md`（PDF 取文 / OCR） |
| 长视频课程 | 四路转写稿：口播 + 画面事实 + 屏幕 OCR + 时间戳（细则见补丁 B 前置） | 讲次 → 主题段 | `bootstrap.md`（抽帧 / 音轨 / ASR / OCR） |
| 播客 / 访谈 / 有声书 | ASR 转写，保留句级时间戳；多说话人尽量分离 | 话题段（10–20 分钟） | `bootstrap.md`（ASR） |

分段后**先建索引**：`段落编号 | 起止定位 | 一句话主题 | 是否含规则`。索引是后续候选池的骨架，也是跨批次去重的依据。

同时记录**版本与时效**：书看版次与出版年份，课程看录制时间与软件版本，播客访谈看集数与发布日。跨版本场景在产物里必须带一句"素材时间 + 可能已过时"，无时间信息标 unknown。

## K0 整篇理解（动手拆之前必须先读懂）

产出「内容总览」，四步不可跳：

1. **结构**：属于什么类型（方法论/传记/哲学/实操手册）；主旨能否压成一句话；3–7 个一级论点及其关系（并列/递进/对比/反驳）；作者要解决的核心问题。
2. **解释**：关键术语按**作者本人的用法**逐个给一句话定义（不是字典义）；用自己的话重述 5–15 条核心主张；标明主张之间的论证链与证据。
3. **批判**：时代局限（哪些前提可能已不成立）、立场盲点、被当作不证自明的假设、最强的反对意见。**这一步的产出直接成为每个能力卡 B 段（Boundary）的来源**，跳过它，产物就会把作者偏见当真理。
4. **应用潜力 + 关键任务清单**：哪些内容可技能化（框架/清单/原则/决策程序/流程/计算/排障），哪些不可（纯史料/纯故事/纯情感）；列出「读者要完成的任务 → 原文位置 → 预期交付物 → 重要性及依据」。这份清单是 K2 覆盖审计的**独立基准**，不得从既有产物反推。

质量门：主旨一句话、骨架 3–7 条、术语按原文实际数量、批判项无证据时标待核查（不编三条凑数）、关键任务清单齐备。

## K1 五路提取（并行优先，串行兜底）

| # | 路 | 查找对象 | 产出 |
|---|---|---|---|
| 1 | 框架 | 思维模型 / 决策框架 / 操作流程 / 排障路径 | 框架候选文件（candidates/frameworks.md） |
| 2 | 原则 | 原则 / 清单 / 规则 / 公式 / 指标口径 / 工作模板字段 | 原则候选文件（candidates/principles.md） |
| 3 | 案例 | 亲历或转述案例、例题（区分性质） | 案例候选文件（candidates/cases.md） |
| 4 | 反例 | 作者警告的失败、陷阱、"我试过不行" | 反例候选文件（candidates/counter-examples.md） |
| 5 | 术语 | 有可操作定义的关键概念 | 术语候选文件（candidates/glossary.md） |

- 每路独立判断，互不带上一个视角的结论；无并行工具时串行执行，产出格式不变，**不得因串行漏路**。
- 五路之间边界模糊可交叉提取，重复留到 K2 去重。

**候选最小字段**（缺字段的候选不得入库）：

```yaml
id: f01                 # 路别缩写 + 序号
title: 逆向思维
type: framework         # framework / principle / procedure / calculation / troubleshooting / case / counter-example / term
locator: 第三讲 第 2 段   # 形态定位，见下方"定位格式"
quote: |                # 原文引用 ≤150 字（英文 ≤100 词），必须逐字
summary: |              # 用自己的话 5–10 行
task_ids: [task-01]     # 对应 K0 关键任务；无对应时必须写明原因
confidence: Observed    # 填初判，K2 复核时可降不可升（升须重新取证）
```

**长文本分块纪律**：单块 ≤5 万字，按章节/讲次/话题段等自然边界切；每块必须附带 K0 内容总览作全局锚点（否则提不出"这段在全篇扮演什么角色"）；块间汇总时合并同一方法但保留全部出处，重复转述不算独立证据。

## K2 三重验证（三关全过才算 verified）

| 关 | 问题 | 判据 |
|---|---|---|
| V1 来源充分 | 可定位的原文是否足以支撑这条规则在限定范围内的内容？ | 单处完整说明即可通过；只有名称、口号、半条公式或缺关键条件 → 不得补全；引用与规则逐项对应，不能只写书名 |
| V2 可执行 | 换一组合法输入，能否按它完成一个明确任务并检验结果？ | 先固定输入与完成标准再纸面演练（walkthrough）；计算型给独立核对的预期值/容差；流程型给必要步骤、交付物、缺输入处理；不得借演练补造原书没有的规则 |
| V3 任务增益 | 固化后能给目标任务带来什么可检查的帮助？ | 至少一种：减少遗漏 / 统一口径 / 稳定格式 / 改善决策 / 识别失败边界 / 省重复操作；不要求作者独创或反常识 |

**判定四档**：`verified`（进入 K3）｜`reference`（有来源价值但不可独立执行，落到 references/ 参考区并登记去向）｜`needs_review`（关键条件缺失或来源冲突，列具体缺口，不入活跃池）｜`rejected`（无原文依据、错误归因或被更完整候选覆盖，附理由与 canonical id）。

**置信标签映射（接本 skill 铁律 1）**：V1 通过且原文单处完整 → Observed；需跨章节组合或需补入外部条件 → Strong inference 并写明两处定位；只有二手转述、无原始定位 → Tentative 且必须同时写进 unknowns。

**覆盖审计**：逐项对照 K0 关键任务清单 → 原文位置 → 候选 → 判定 → 最终去向；重要任务无候选时先扩读，仍缺则如实记缺口。重要但待核查的内容不得静默消失。

## K3 晋级门（知识保留 ≠ 独立入口）

五条判据，前三条必须全过：

| # | 判据 | 问题 |
|---|---|---|
| 1 | 独立意图 | 用户会不会不提书名/课名，单独提出这个任务？ |
| 2 | 独立契约 | 有独立的输入、步骤、输出与完成标准，而不只是一个观点或术语？ |
| 3 | 独立运行 | 不加载全篇和兄弟能力也能正确执行？ |
| 4 | 独立复用 | 会在多个任务/项目里重复调用，或被其他 skill 组合？（与 5 至少过一条） |
| 5 | 独立评测 | 能写出正向、负向、近邻用例与输出断言？（与 4 至少过一条） |

- 通过 → `promoted`（编译成独立子能力，配 pack 模式）；未通过 → `router`（保留为能力卡，挂在入口的分诊表下，不算失败、不删）。
- **入口数软预算 8**（1 个路由入口 + 晋级数量）。超出时按调用频率、跨场景复用、独特性、证据强度、触发可分性排序，其余降为能力卡。
- 判定的目标函数：用最少的可发现入口覆盖最多高价值意图，同时不让任何能力失联。

## K4 能力卡六段（R / I / A1 / A2 / E / B）

- **R（原文）**：引用 ≤150 字 + 完整定位（章节+段落 / `mm:ss` / 说话人）。外文原文配自己的中文翻译，不用现成译本。
- **I（自述）**：用自己的话重写核心骨架 5–15 行；标准是"没读过原文的人读完能明白它在做什么"；写成"作者说了 X"即为失败。
- **A1（示例）**：优先用原作者案例/例题，标注类型与来源，作者未交代结果就写"未说明"；无案例时可做**明确标记的合成演练**，不得冒充作者经历或现实结果。
- **A2（未来触发）★**：写清三件事——用户什么情境遇到（3–5 条）、这些情境的语言信号是什么（用户会怎么说，中英关键触发词双写）、与相邻能力的区别。A2 直接进产物 frontmatter 的 `description`，它决定这个 skill 会不会被调用。
- **E（执行）**：1-2-3 可执行步骤，每步有可判断的完成标准；有判停点就显式写"第 2 步若 X 则跳到第 5 步"；给出输入契约（必需字段/单位/适用条件，缺什么先问、不静默猜值）与输出契约（结构/格式/完成标准；计算类给公式、顺序、舍入与容差）。
- **B（边界）**：什么时候不要用、作者警告过的失败模式、K0 批判阶段揭示的作者盲点、易混淆的相邻方法。缺 B 的产物一定会在不该用的时候被调用。

## K5 压力测试（交付前必须给出）

1. **触发测试**：正向用例（应命中）、负向用例（不该命中）、近邻用例（相邻能力抢调用）各 ≥1 条，检查 description 与分诊表。
2. **输出测试**：给定输入，断言产出的结构、字段与判停点；计算类核对独立算出的预期值。
3. **基线对照**：同一任务在没有该 skill 时怎么做，逐项对比收益；不凭自评宣称更好。
4. **回炉条件**：触发误判、演练算不出预期值、B 段缺失 → 回到 K2 或 K3 重做，不带病编译。

## 定位格式（按形态）

| 形态 | 定位写法 | 示例 |
|---|---|---|
| 书（纸质/PDF） | 章节 + 段落序号（有页码加页码） | 第 4 章 §4.3 第 2 段（p.127） |
| 书（电子版无固定页码） | 章节 + 段落 + 阅读器位置 | 第 4 章 §4.3 第 2 段（loc.1841，版本：<阅读器/版本号>） |
| 长视频 | `mm:ss`（超 1 小时用 `hh:mm:ss`）+ 画面区域 | 42:15 + 屏幕左侧终端窗口 |
| 播客 / 访谈 | `mm:ss` + 说话人（已知时） | 18:40（主持人）+ 嘉宾回答段 |

## 长内容三条纪律

1. **判断时刻密度**：每章（书）或每 20 分钟（音视频）至少产出 1 条可触发规则；某段确实没有，必须在覆盖审计里写明"纯叙述/纯铺垫"，不许空话凑数。
2. **不得跨段拼接**：A 章的前提不能搬到 B 章的结论上；跨章组合出的规则必须标 Strong inference 并注明两处定位。
3. **跨批次一致**：分批处理时维护全局术语表与去重表（格式见 `multi-turn-mode.md`），同一原则只收一次；重复时保留定位更精确的那条。多来源说法冲突（两本书阈值不同、两个讲者结论相反）时，按 `pack-mode.md` 的冲突登记表处理，**禁止擅自择一**。

## 出口：single 还是 pack

判断时刻 ≤ 15 条且单来源 → single（章节级详解放 references/）；> 15 条或四类素材混用 → pack（`pack-mode.md`）。素材单轮读不完 → multi-turn，两者可叠加：先分段多轮提取，最后按 pack 编译。

## 停止条件

满足任意一条即停止展开，转 K4：

- 连续两轮扫描无新增候选；
- K0 关键任务清单 100% 有候选或有明确缺口记录；
- 剩余部分为纯叙述（无规则、无案例、无反例），继续读不会产生可触发规则。

## fallback（不要走的路）

- 当只有二手笔记/书评/课程总结、没有原始素材时：不要继续蒸馏——没有原始定位就定不了置信等级，终止并要求补原始素材。
- 当只有 ASR 文本、没有画面事实（长视频）时：不要把"讲者提到但画面未捕获"的公式、代码、图表写成结论，该处标 unknown 并给截图探针。
- 当一章读完提不出规则时：不要硬造规则凑密度，如实记录"纯叙述段"并说明理由。
- 当候选只够"reference"却为了凑入口强行晋级时：不要晋级——留在 router 能力卡里，比一个永远误触发的入口更有价值。
- 当作者观点与可验证事实混在一起时：不要把观点写成事实，观点标 Strong/Tentative inference。

## 常见失败模式

1. I 段写成书摘（"本章作者说了 X"）——那是抄书，不是解释，重写。
2. A2 太宽（"需要思考时"）——永远不会被精准调用，必须给可识别的语言信号。
3. E 段只有哲学没有动作（"保持客观"不是步骤，"列出 3 个最不希望发生的结果"才是）。
4. 跳过 K0 的批判阶段——产物把作者偏见当真理，且 B 段无来源。
5. 把合成演练冒充书中案例——A1 用来展示方法怎么用，不能靠虚构结果制造权威。
