# 补丁 F：音频（播客 / 会议录音 / 访谈 / 有声书）

适用素材：纯音频文件、播客、会议录音、电话录音、访谈录音、有声书——**没有画面轨**，因此补丁 B 的"四路对齐"不适用。

## 前置：音频转写稿

1. ASR 转写，保留句级时间戳（多说话人时尽可能做说话人分离）。
2. 无说话人分离时，说话人归属一律标 unknown，不得按语气/内容猜"这是老板说的"。
3. 转写噪声（同音错字、语气词、口误）不得当作术语或规则；不确定的词按原样保留并标 `[unclear]`。
4. 工具链见 `bootstrap.md`；ASR 不可用则终止，要求用户提供字幕或文字稿。

## 提取维度（五路）

1. **时序观点链**：把"先讲什么、后讲什么"抽成有序论点，每段挂 `mm:ss`（超过 1 小时用 `hh:mm:ss`）。
2. **决策规则**：讲者出现"如果……就……""这种情况我一般……"时，转成"条件→动作"。
3. **隐性前提**：适用人群、前置条件、版本/环境、成本约束——音频里这类信息最容易被漏，且最影响可复现性。
4. **反例**：讲者明确说"这样不行""我试过，会……"的片段，转成 fallback 分支。
5. **术语**：仅收作者给出可操作定义的概念，不做词汇表堆砌。

## 额外要求

- **禁止补画面**：口播里出现"看这张图""这里点一下"时，不得推断画面内容——该处标 unknown，并给探针：索取对应视频/截图（转补丁 B 或 C）。
- 单一说话人长音频按主题切段处理，跨段维护术语表与去重表（见 `multi-turn-mode.md`），防止同一原则被重复收录。
- 观点 vs 事实分开：讲者的主观判断标 Strong/Tentative inference，只有可外部验证的内容才可能到 Observed。
- 时效声明：记录发布时间或录制时间；操作性内容注明"录制于 <时间>"，跨版本场景提示可能已过时。

## 与总纲的衔接

- 阶段 1 候选定位格式统一为 `mm:ss`（句级）+ 说话人（已知时）。
- 阶段 2 三类时刻来源：决策规则 → 路由判断；反例 → 放弃判断；时序观点链的自然收束 → 结束判断。
- 阶段 3 产物通常不需要 scripts/；若含计算类规则（如报价、排期公式），把公式与样例算例放 references/。
