# 网页素材体检探针（URL 素材在阶段 0 必读）

当 MATERIAL_TYPE 是网页/在线课程/在线文档，或 MATERIAL_REF 是 URL 时，阶段 0 按以下探针路径依次执行，**每一步记录判定与证据，不跳步**。

## 探针路径（按序）

| 步骤 | 动作 | 判定 |
|---|---|---|
| 1 | `webfetch` 抓取（markdown 格式） | 拿到实质内容（正文/章节/标题）→ 可读，直接进阶段 1 |
| 2 | 步骤 1 只返回 "请开启 JavaScript" / 空壳提示 → `curl -s <url>` 看原始 HTML | HTML 含正文（服务端渲染）→ 可读；只有 loading 骨架 / `<div id=app>` 空壳 → 是 SPA，进步骤 3 |
| 3 | 用内置浏览器打开 URL | 浏览器能渲染 → 内容对**用户**可见，但 agent 仍拿不到 DOM 数据 → 记录"页面可浏览但不可蒸馏"，进步骤 4 |
| 4 | 登录墙判定：URL 路径含 login/user/account、页面出现"请登录/扫码"、curl 无数据且浏览器需登录 | 命中任一 → 判定"需登录态"，走 fallback |
| 5 | 判定"公开 SPA"（无需登录但 agent 取不到数据） | 走 fallback（同登录墙处理，素材补方式不同） |

## 判定矩阵（输出给用户）

| 判定 | 后续动作 |
|---|---|
| 可读（步骤 1/2 成功） | 进阶段 1，定位格式为"页面路径 + 板块标题" |
| 需登录态 | 终止蒸馏，明确告知用户：请提供**页面截图**（走补丁 C）、**视频/字幕文件路径**（走补丁 B）或**文本导出** |
| 公开但 agent 不可读 | 同上终止，但说明"内容你自己能看到，我拿不到"——请用户复制正文文本或截图 |

## fallback（不要走的路）

- 当 curl 拿到的是 SPA 骨架时：不要凭 URL 或页面标题猜课程内容硬写——没有原始定位就无法标置信标签。
- 当页面需要登录时：不要尝试猜 API 路径或伪造请求硬抓——改走"向用户要素材"的退回方案。
- 当 browser 打开成功时：不要把"浏览器能打开"当作"素材可读"——渲染成功不等于 agent 获得了内容。

## 经验锚点（Tentative inference，来源：本 skill 开发会话，未独立复核）

- `ai.icve.com.cn` 课程页：Vue SPA + 登录墙，webfetch 与 curl 均只返回骨架，判定"需登录态"，向用户要截图/视频文件。
- SPA 判据（Strong inference）：HTML `<body>` 内只有 `<div id=app>` 空容器 + loading 动画样式，无正文文本节点。
