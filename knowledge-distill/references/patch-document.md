# 补丁 D：书籍 / 长文档 / 规范标准

适用素材：书籍、长文档、规范标准（国标/行标/内部规范）。

## 提取维度（五维并行，避免单线阅读遗漏）

1. **框架**：核心模型、分层结构、因果链。
2. **原则**：可执行规则，逐条转成"条件→动作"，标注适用边界。
3. **案例**：作者给出的正面案例，抽成"情境→做法→结果"三元组。
4. **反例**：作者明确警告的错误做法，转成 MUST NOT / fallback。
5. **术语**：作者自定义且有明确定义的概念，附原文定义位置。

## 额外要求

- 拒绝摘要：产物是带触发条件的技能，不是章节概括。每章至少产出 1 条可触发规则，否则说明该章为何无可提取内容。
- 忠于原文：原则性表述必须能回溯到具体章节段落；AI 的理解性复述不得冒充原文观点。
- 规范类文档（国标/行标/内部规范）：条款编号必须保留，强制条款（应/必须）与建议条款（宜/可）严格区分，不得把建议升格为强制。
- 版本与适用范围：记录标准号、发布年份、替代关系与适用领域，避免跨版本混用。
- 长文档分批处理时，需维护跨批次的全局术语表与去重表，防止同一原则被重复收录。

## 与总纲的衔接

- 阶段 1 的候选单元定位格式为"章节 + 段落（或条款号）"。
- 阶段 2 中：案例 → 路由判断素材（什么情境用什么做法）；反例 → 放弃判断（fallback）；框架中的因果链终点 → 结束判断素材。
- 跨批次处理时每轮开头先复述上一轮结论编号，保证可追溯（见 multi-turn-mode.md）。
